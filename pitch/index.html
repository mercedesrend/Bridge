Under the hood

Built to be trusted, not just to work.

Grounded

Every claim traces to PubMed or ClinicalTrials.gov. The model summarizes retrieved evidence — it never generates a citation.

Consented

Recording is enforced server-side. The API returns 403 without consent, so it cannot be skipped in the interface.

Nothing kept

Sessions live in memory and die with the process. No name, no address, no insurance, no immigration status.
